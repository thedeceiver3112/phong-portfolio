# Nguyen Tran Hai Phong Portfolio

Static GitHub Pages portfolio for Nguyen Tran Hai Phong.

## Deploy with GitHub Pages

Use the repository settings:

1. Go to **Settings > Pages**.
2. Choose **Deploy from a branch**.
3. Select branch **main** and folder **/**.
4. Save.

The site will be available at:

`https://thedeceiver3112.github.io/phong-portfolio/`
